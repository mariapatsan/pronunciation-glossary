# pronunciation-glossary

# Произносительный глоссарий

Выполнили Полторацкая Анастасия, Пацан Мария, Шевелева Мария 2 курс ПОО
Интерактивное упражнение по профессиональному английскому языку.
Три группы терминов: слово + слово = словосочетание.

## Технологии

- Семантический HTML
- CSS Grid, адаптивная вёрстка
- JavaScript: DOM, события, HTMLAudioElement, SpeechSynthesisUtterance

## Структура

├── index.html
├── styles.css
├── app.js

## Три комбинации

1. cyber + security = cybersecurity
2. cloud + storage = cloud storage
3. machine + learning = machine learning
